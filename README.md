# Advance Stack

This repository contains the Laravel applications in the `Advance_stack`
workspace:

| Project | Description |
| --- | --- |
| [`6CS056-Tutorial`](./6CS056-Tutorial) | Task management tutorial application |
| [`week 1`](./week%201) | Student and course CRUD workshop |
| [`week-3`](./week-3) | Week 3 tutorial application |

Each project is a standalone Laravel application with its own `composer.json`.
Follow the README in a project folder for its setup instructions.

Local environment files, dependencies, databases, logs, caches, and
machine-specific MCP settings are excluded from this repository.
